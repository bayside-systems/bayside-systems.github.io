Wave.next

Shared document workspace with live editing, contributor attribution, and AI agent collaborators.

Shared Document Workspace

Wave.next is a collaborative workspace where people and AI agents write together. Everyone in a workspace edits the same document at the same time, and the app merges everyone’s edits automatically so no one’s work gets overwritten.

If your team needs to write together — or you want AI agents to contribute to shared documents, Wave.next is that workspace, local-first: the whole stack runs on your own hardware.

Why Collaborative Editing?

Most editors were built for one person at a time. When a whole team — and their AI agents — need to build a document together, the usual tools fall apart: edits get lost, authorship gets blurred, and past versions disappear.

Wave.next is built for that situation. Edits from everyone, human or agent, merge automatically, and every piece of text keeps track of who wrote it.

What Wave.next Provides

Live Editing
When you type, collaborators see your changes instantly. The full history of the document is kept, so you can look back and see what the document looked like at any earlier point.

Contributor Attribution
Each part of the text shows who wrote it, with color-coded regions and a contributor legend. That attribution survives editing and page reloads, so authorship stays clear.

Workspaces and Invitations
Create a workspace, share its code, and invite teammates. Membership controls who can see the documents, the discussion, and the workspace’s compute backends.

Agent Collaborators
Add an agent from the Collaborate panel: give it a name, point it at a chat endpoint, and set its instructions. The agent joins the workspace under its own identity, and when you address it in the discussion pane — @ThreeEight add whitespace to organize the document — it reads the current document and returns a revised version.

Discussion and Presentation
Every document has a discussion pane. Messages stay with the workspace, and any message can be added to the document as an attributed note. A presentation view renders the live document into a print-ready paper layout, with the LaTeX source available for export.

Code Workspaces
Paste a public git URL, pick a branch, and import the repository into a code-editing workspace with a foldable file tree and a monospace editor.

In-Browser SSH Terminal
Open an SSH session from the browser to a machine that already runs your AI tools (Claude, Codex, Grok, OpenCode) or a plain shell — no separate terminal app needed.

Computelet Binding
Code and finance spaces can bind to a running Bayside computelet, opening a terminal straight into the guest. No manual address entry.

Runs on Your Hardware

The complete stack — web app, identity server, database, and sync service — runs on your own machine. Your documents, members, and agent settings stay local by default; hosted operation is an option, not the default.

Use Cases

  • Team and research writing with full revision history and clear authorship
  • Agent-assisted documents: address an agent from the discussion pane to organize, format, or expand content
  • Code collaboration: import public git repositories and edit code together
  • Multi-workspace research groups with invitations and per-workspace compute pools
  • Paper workflows: render the live document to a presentation layout and export the LaTeX source
